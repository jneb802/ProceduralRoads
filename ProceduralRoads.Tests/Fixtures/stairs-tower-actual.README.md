# Saved Tower landing regression

`stairs-tower-actual.txt` is a curated numeric input from an investigation of stairs laid onto a raised landing. It retains the saved placement's levelling operations and exact 90-by-90 natural/final vertex grid, plus one **controlled, declared** road request, tail and planner budgets. The request was not recovered from historical generation.

The fixture omits machine paths, accounts, world UID/name, proxy and ZDO identities, assembly/network identities, and raw native headers. It contains no world save or game binary. The adjacent SHA-256 file identifies these curated payload bytes. The `input-sha256` row is only a provenance label linking the private original native pair; it does not hash this sanitized file or certify omitted inputs.

The test adapter uses `PlacedLocations.Read` and `PlacedLocationGround.Sampler`, retaining every recorded vertex without another interpolation implementation. The captured global footprint index was unavailable: replay deliberately treats every cut as protected, a conservative diagnostic boundary. Mountain biome is the declared native observation. A passing replay does not prove all native callbacks were captured or establish native materialization, support, walking or save/reload acceptance.

The retained baseline floor's walking top was 185.810776 m; the independently verified interior grid vertex (-4800,1739) was 186.306931 m. This fixed negative control and the reached candidate's complete closed walking surfaces reuse the existing independent prefab-surface test oracle. Production connected-region predicates do not define the oracle's expected raised terrain.
